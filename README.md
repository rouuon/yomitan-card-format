# Japanese Anki note type

<img width="1080" height="1406" alt="image" src="https://github.com/user-attachments/assets/670a7b06-da52-4999-bb72-391413680ead" />

This note type uses targeted sentence cards; fill in `UseVocabCard` to make a vocabulary card instead.

Lowercase fields match Yomitan's fields and can be autofilled through the extension.

Pitch accent coloring highlights the target word, reading, pitch diagram, and definition panel according to the accent pattern.

Enable text to speech in the styling config to use system voices for notes without audio.

Change `--dictionary-order` in the styling config to reorder dictionaries in `glossary-plain` definitions; unlisted dictionaries follow in their field order.
